# Scene resources

The source tree includes the project-owned finite reflector (`reflector.xml`
and `reflector.obj`). The installed Sionna RT package supplies its own built-in
scenes, including Munich. Neither needs the external Town02 package.

Town02 geometry is a **user-supplied external resource**, required only when a
Town02 configuration is selected. The XML scenes, PLY meshes and CSV positions
are not downloaded from an invented public URL and are not redistributed by
this repository. Obtain the complete `Sionna_Town02` package from its original
provider or your existing authorized copy. Its own terms apply.

```bash
WIWO_TOWN02_SOURCE=/path/to/Sionna_Town02 scripts/platform/install --no-browser
# With dependencies already installed:
.venv-full/bin/python -m wiwo_ma.platform.town02 import --source /path/to/Sionna_Town02
.venv-full/bin/python -m wiwo_ma.platform.town02 status --require
```

The package must contain its original provider-supplied SHA-256 manifest at the
root, under its original filename, and `Town2_xml/` with the original
`town2_xml.xml`, `town2_3mat.xml`, `meshes/`, `car_coordinate/` and
`material_manager.py`. The importer verifies source hashes before copying
resources to the Git-ignored `assets/town02/` directory.

The strict ITU XML and per-mesh audit are generated locally from that import.
Their generation code, exact-label rules and experiment JSON are public source;
their presence in Git does **not** mean the external map is installed.
Relative permittivity and conductivity come from the pinned Sionna package.

`town02 status` distinguishes `not_imported`, `incomplete` and `available`.
Missing XML, audit or referenced PLY files in an existing import are errors.
The full hash checks remain in `town02 check` and `town02_materials check`.

Public CI uses 25 independently authored quadrilaterals generated by
`tests/platform/test_town02_resources.py` to exercise import, ITU assignment,
actual PLY reading and mechanics. They are not Town02 geometry. Tests marked
`town02` retain all assertions against the full external scene; use
`--require-town02` to make a missing map a test failure.
