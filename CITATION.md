# Citing WiWo-MA

Please identify the software version and repository when using the platform:

> WiWo-MA Platform, version 1.0.0. A Physics-Grounded Interactive Simulation
> Platform for Movable Antenna Systems.
> https://github.com/ReamonYim/WiWo-MA

Formal author metadata and a paper/DOI have not been supplied. This software
reference does not invent authors, affiliations or a publication. A complete
machine-readable citation can be added once the authors confirm those details.

When reporting results, also identify the configuration, SDK version, physical
port model, sampling interval and the independent numerical validation scope.
